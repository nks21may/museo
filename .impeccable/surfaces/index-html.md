# Surface: museo (index.html)

Mode: Experience. Personal collection of live twigl shaders; the owner is the visitor.
Job: open it and see a piece alive at once; switch pieces; reveal source on demand.
Constraints: one shared WebGL2 context; only on-screen work renders; reduced resolution for the guide; code hidden until asked; avoid template look, UI covering the work, slowness.

## Direction contract

THESIS: Each shader is a channel on air; the museum is a signal you tune. Refuses the category default: title + grid of cards + modal viewer.

OWN-WORLD: Absolute black. One red (#b40000 family) reserved for what is on air: channel number, active cursor, live marker. Everything else is dim grey. Blackletter (UnifrakturMaguntia) only for channel idents; Doto dot-matrix for OSD numerals (a dot-matrix on-screen display is native to broadcast), Martian Mono for teletext and controls; red token #c40000 (#b40000 family, raised to clear 3:1 on large numerals). No borders-with-radius, no shadows, no cards.

STORY: You land inside a channel playing full-screen. The OSD tells you where you are, then fades. Arrows/wheel/swipe change channel through a short cut-snow-tune sequence. G opens the channel guide (strict label grid, live previews). I opens the teletext page with the original twigl source, author, link, char count.

FIRST VIEWPORT: The piece at full bleed, 100% of the viewport. Top-right: red "CH 03" in large OSD numerals, blackletter title under it, both fading after ~3s. Bottom-left: a single dim line of key hints that fades too. The work is the only thing left.

FORM: Late-night pirate TV broadcast; candidate 7 of 7 on my ordered list; seed key 260e4f69. Raises: red only on air (vu); deep links #/03 + history (hypercard); strict guide label grid (sneaker); channel change as a measured sequence (versailles).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
